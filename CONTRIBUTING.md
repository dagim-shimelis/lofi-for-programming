# Contributing

Thanks for helping improve Meadow FM.

## Development

1. Fork and clone the repository.
2. Install Bun 1.2.14 or newer.
3. Run `bun install --frozen-lockfile`.
4. Start the app with `bun run dev`.
5. Before opening a pull request, run `bun run check`.

## Pull requests

- Keep changes focused and explain the user-facing behavior.
- Preserve keyboard navigation, visible focus, reduced-motion support, and responsive layouts.
- Do not commit generated output, local environment files, downloaded music, or third-party artwork without documented redistribution rights.
- Add playlist entries only when their SoundCloud URLs are public and playable through the official widget.
- Do not commit secrets or credentials.
