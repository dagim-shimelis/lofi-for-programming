# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through GitHub’s security advisory feature for this repository.

Include the affected file or flow, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Scope

This is a client-side application. It does not require application secrets or a backend database. SoundCloud playback is provided by the official embedded Widget API.
